# Bookmarklets - ToolkitJS

![JavaScript Logo](jslogo.png)

## 🚀 Overview

ToolkitJS is a powerful, all-in-one bookmarklet toolkit that brings essential browser utilities and AI-powered features to any website. No extensions needed – just a simple bookmark that works everywhere!

## ✨ Features

### 🤖 AI-Powered
- **Highlight to Ask AI**: Select text on any page and get instant AI-powered responses displayed directly in the toolkit menu

### 🎨 Productivity Tools
- **Calculator**: Quick mathematical calculations with a built-in calculator
- **Text to Speech**: Convert selected text or custom input into speech
- **Find & Replace**: Search and replace text across the entire page
- **QR Code Generator**: Create QR codes from any text or URL instantly

### 🌐 Web Enhancements
- **Dark Mode**: Toggle dark mode on any website with smart color inversion
- **Edit the Site**: Make any website editable for quick annotations
- **Skip YouTube Ads**: Automatically skip ads on YouTube videos

### 📸 Media Tools
- **Screenshot**: Capture screenshots with browser-native tools (guidance provided)

## 🎯 How to Use

1. **Create a new bookmark** in your browser
2. **Copy the entire content** of `toolkit.js`
3. **Add `javascript:` prefix** before pasting the code in the bookmark URL field
4. **Click the bookmark** on any webpage to activate the toolkit!

Example bookmark URL format:
```
javascript:(function(){...entire toolkit.js code...})();
```
